# leplik/homebrew-tap

Homebrew casks by [leplik](https://github.com/leplik).

```sh
brew install --cask leplik/tap/tg-granola-autorecord
```

| Cask | Description |
|---|---|
| [`tg-granola-autorecord`](https://github.com/leplik/tg-granola-autorecord) | Record Telegram calls in Granola automatically |

Casks are updated by each project's release script.
